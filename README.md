# ST Helper

Небольшой помощник для собеседований под Windows 10 (2004+) / 11. Полупрозрачное окно поверх всех окон,
скрытое от демонстрации экрана и записи. Слушает системный звук (голос собеседника в звонке), распознаёт речь
через Groq Whisper и стримит короткий ответ от первого лица через Groq LLM.

Стек: Tauri 2 (Rust) + ванильный HTML/CSS/JS. Все запросы к Groq идут из Rust, ключ во фронтенд не попадает.

![Демо: вопрос распознаётся, ответ печатается в окне](docs/demo.gif)

<sub>Анимация воспроизводит интерфейс 1:1, но отрисована отдельно: настоящее окно не попадает в запись экрана, на то и защита.
Скрипт: `docs/make_demo_gif.py`.</sub>

## Скачать

Готовые файлы лежат в [Releases](../../releases/latest):
- `ST-Helper.exe` — портативная версия (~7 МБ), запускается без установки;
- `ST-Helper_0.1.0_x64-setup.exe` — установщик (~1,8 МБ).

Нужен только бесплатный ключ Groq, его вводят в настройках (`Ctrl+Shift+S`).

## Сборка из исходников

### Зависимости

- Node.js 18+ (`node -v`)
- Rust stable с toolchain `x86_64-pc-windows-msvc` (https://rustup.rs)
- Visual Studio Build Tools 2022 с компонентом «Desktop development with C++»
- WebView2 Runtime (в Windows 11 уже установлен)
- Бесплатный ключ Groq: https://console.groq.com → API Keys

```bash
npm install
```

### Запуск и сборка

```bash
npm run tauri dev
```

```bash
npm run tauri build
```

Результат сборки:
- `src-tauri/target/release/st-helper.exe` — готовый исполняемый файл, можно запускать без установки;
- `src-tauri/target/release/bundle/nsis/ST Helper_0.1.0_x64-setup.exe` — установщик.

## Первый запуск

1. Запустите приложение. Окно появится в правом верхнем углу.
2. Нажмите `Ctrl+Shift+S` (или ⚙ в окне) и вставьте ключ Groq, при желании резюме и описание вакансии. Нажмите «Сохранить».
3. Включите любое видео с речью: при вопросе окно покажет «Распознаю…», затем «Генерирую ответ…» и сам ответ.
4. Если речь не ловится или ловится шум, подстройте «Порог речи» по индикатору уровня в настройках.

## Настройки

Хранятся локально в `%APPDATA%\com.sthelper.overlay\settings.json` (ключ Groq лежит там открытым текстом, в код не попадает).

| Параметр | По умолчанию |
|---|---|
| Язык распознавания | `ru` (пусто = автоопределение) |
| Язык ответа | русский |
| Модель | `openai/gpt-oss-120b` (`llama-3.3-70b-versatile` в Groq больше нет; список моделей: console.groq.com/docs/models) |
| Порог речи (RMS) | 0.015 |
| Пауза конца реплики | 1.2 с |
| Мин. / макс. длина реплики | 0.7 с / 25 с |
| Непрозрачность фона | 70% |
| Микрофон как второй источник | выключен |

Реплики с микрофона обрабатываются так же, как системный звук (вариант для очного собеседования рядом с ноутбуком).

## Горячие клавиши

Работают глобально, даже когда окно не в фокусе. Все заданы в одном месте: `src-tauri/src/hotkeys.rs`.

| Клавиши | Действие |
|---|---|
| `Ctrl+Shift+H` | показать / скрыть окно |
| `Ctrl+Shift+C` | очистить ответ (и остановить текущую генерацию) |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | прокрутка ответа |
| `Ctrl+Shift+P` | пауза / продолжить прослушивание |
| `Ctrl+Shift+M` | сквозной режим (мышь проходит сквозь окно) |
| `Ctrl+Shift+S` | настройки |

Если какую-то комбинацию уже заняла другая программа, в строке статуса при запуске появится сообщение.
Обратите внимание: в Microsoft Teams `Ctrl+Shift+M` — выключение микрофона; при конфликте поменяйте комбинацию в `hotkeys.rs`.

В обычном режиме окно перетаскивается за верхнюю полоску, размер меняется уголком справа внизу.

## Как это работает

- Звук: WASAPI loopback (cpal, input-поток на устройстве вывода по умолчанию), смена устройства отслеживается раз в секунду.
  Звук приводится к 16 кГц моно 16 бит. Детектор речи по энергии (RMS, сглаживание); реплика заканчивается после паузы,
  короткие куски и тишина не отправляются, длинные режутся принудительно. Аудио на диск не пишется.
- Распознавание: `POST /audio/transcriptions`, `whisper-large-v3-turbo`; сегменты с высокой вероятностью «не речь»
  и типичные галлюцинации Whisper («Продолжение следует…») отбрасываются.
- Вопрос или нет: короткие реплики без признаков вопроса отсекаются эвристикой без запроса к LLM; остальное сразу уходит
  в генерацию, а промпт велит модели ответить `NO_ANSWER`, если ответ не нужен. Лишнего запроса нет, задержка не удваивается.
- Ответ: `POST /chat/completions` со `stream=true`, контекст — последние 6 реплик. Новый вопрос останавливает генерацию предыдущего ответа.
- Защита от захвата: `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` для окна подсказок и окна настроек.

## Отладка

В debug-сборке (`npm run tauri dev`) переменная окружения `ST_HELPER_NO_PROTECT=1` отключает защиту от захвата,
чтобы можно было сделать скриншот интерфейса. В консоль пишется длительность каждой найденной реплики (без содержимого).
В release-сборке этого нет.
